# Security Policy

## Supported Version

Security fixes are applied to the latest Codex Vision release for Windows 10/11.

## Reporting A Vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not publish account tokens, cookies, `auth.json`, conversation files or proof-of-concept data that belongs to another person.

Include the affected version, Windows version, impact, reproduction steps and a minimal proof of concept. You should receive an acknowledgement within seven days.

## Privacy Boundary

Codex Vision has no telemetry service, account system or hosted backend. It communicates with the locally installed Codex runtime and reads local rate-limit records. A change that introduces any new network destination, credential access or analytics requires explicit documentation and review.
